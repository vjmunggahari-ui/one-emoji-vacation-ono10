# One Emoji, One Dream Vacation

One emoji for the dream vacation: 🏝 DESERT ISLAND.

A desert island is the whole postcard in a single glyph — white sand, one palm, nobody else there. It won a relay tournament 3/3 games, 12/12 calls against the beach, the diving mask and a Japanese castle, and beat the volcano fix 0/3 in the cruel-judge re-test. The program writes exactly that one emoji (U+1F3DD, one code point, 4 bytes, no trailing newline) to `entry.txt`.
